# RESTAURANT APP PORTFOLIO

This is a restaurant ordering app made as my portfolio.

# Features:

+User registration and login
+Mobile and Desktop layout
+Mock checkout (no actual payment is processed)
+Cart system
+Backend that provides mock data (restaurant, food, orders, reviews), made using Supabase

# How to use

Visit https://restaurant-frontend-supabase.vercel.app/ and register. Since this is a portfolio, email verification is not required.

# Note

This project uses Supabase's free tier, which may pause the backend after a period of inactivity. If the site is unavailable, please contact me and I’ll restore it.
